1 · User Action Pseudo-classes

These respond to what the user is doing right now — hovering, clicking, or focusing.

Try it — hover, click, or press Tab to focus
/* :hover — mouse-over */ .btn:hover { background: #E94560; transform: translateY(-3px); box-shadow: 0 6px 20px rgba(233,69,96,0.35); } /* :focus — keyboard/tab navigation */ .btn:focus { outline: 3px solid #E94560; outline-offset: 3px; } /* :active — press/click */ .btn:active { transform: scale(0.97); background: #c0392b; } /* ::before — inject star icon */ .btn-star::before { content: "★ "; } /* :visited — link already opened */ a:visited { color: #7C3AED; }

2 · Structural Pseudo-classes

Pick elements based on their position in the DOM — first, last, every 2nd, etc.

List — hover over items too!
  • 🥇 First child — dark blue, bold
  • Second child — even row (light blue)
  • Third child — odd row
  • Fourth child — even row (light blue)
  • Fifth child — odd row
  • 🏁 Last child — pink, bold
/* :first-child */ li:first-child { background: #EEF2FF; font-weight: 700; } /* :last-child */ li:last-child { background: #FFF0F3; color: #E94560; } /* :nth-child(2n) — every even row */ li:nth-child(2n) { background: #F8FAFF; } /* :hover on list items */ li:hover { background: #E0E7FF; }

3 · Form & Input Pseudo-classes

Target inputs by their state — focused, valid, invalid, disabled, checked.

Interact with the form below
/* :focus — active input */ input:focus { border-color: #0F3460; box-shadow: 0 0 0 3px rgba(15,52,96,0.15); } /* :valid — correct email entered */ input[type="email"]:valid { border-color: #059669; } /* :invalid — bad email format */ input[type="email"]:invalid:not(:placeholder-shown) { border-color: #E94560; background: #fff5f5; } /* ::placeholder — hint text style */ input::placeholder { color: #aaa; font-style: italic; } /* :required — red left border */ input:required { border-left: 4px solid #E94560; } /* :disabled */ input:disabled { background: #f0f0f0; cursor: not-allowed; } /* :checked — style sibling label */ input[type="checkbox"]:checked + label { color: #E94560; font-weight: 700; }

4 · Pseudo-elements (::)

Target virtual parts of an element — add content, style the first line, or change selected text.

::before — decorative opening quote

CSS pseudo-selectors let you style elements based on their state or position without adding extra HTML classes or JavaScript.

::after — "NEW" badge injected after element

::first-line — first line styled differently; also try selecting text (::selection)

This is the first line of the paragraph, styled in coral-red and bold.
The rest of the paragraph appears in the default body style. Notice how only the first rendered line gets the special treatment — not the first sentence. Try selecting any text on this page to see ::selection in action!

/* ::before — quote decoration */ .blockquote-demo::before { content: "\201C"; /* Unicode left double quote */ font-size: 4rem; color: #E94560; position: absolute; left: 0.6rem; top: -0.2rem; } /* ::after — NEW badge */ .badge-item.new::after { content: "NEW"; position: absolute; top: -8px; right: -8px; background: #E94560; color: #fff; font-size: 0.6rem; padding: 2px 5px; border-radius: 4px; } /* ::first-line */ p.first-line-demo::first-line { font-weight: 700; color: #E94560; font-size: 1.1em; } /* ::selection — highlighted text */ ::selection { background: #E94560; color: #fff; }
